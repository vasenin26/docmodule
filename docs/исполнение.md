# Исполнение

Исполнение является структурой хранящей информацию о выполнении агентом техплана.
При создании исполнения создаётся чат и задача для агента. Чат привязывается к исполнению.

После обработки задачи агентом, в исполнение записывается описание внесённых изменений и статус исполнения.

Хранимые значения:

- id
- content
- techplane_id
- chat_id

Исполнение и связанный чат можно просмотреть на отдельной странице.
