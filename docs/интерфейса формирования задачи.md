# Интерфейс формирование задачи

Задача формируется на основе разницы между текущей и предыдущей задачами.

При утверждении задачи открывается новая страница на которой отображается блок с описанием задачи.
Внизу блока отображается кнопка "экспортировать", на данном этапе кнопка не функциональна - при нажатии не происходит никаких действий.
