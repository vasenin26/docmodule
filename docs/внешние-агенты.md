Задачи выполняются внешними агентами. 
Пользователь может создать в рамках проекта агента.
У агента есть JWT токен с помощью которого агент авторизуется при подключении к АПИ.
JWT токен выдаётся системой при создании агента. 
Пользователь может сгенерировать новй JWT токен для агента, старый токен в этом случае будет анулирован.

## Управление агентами

Для управления агентами предназначен интерфейс со списком агентов. 
Ссылка на страницу списка агентов доступна в боковом меню если выбран проект.

### Список агентов

На странице отображается таблица со списком агентов. В таблице отображается название агента и дата его создания.

В верхней части страницы доступна кнопка "создать" которая отправляет пользователя на страницу создания агента.

В таблице для каждого агента доступны кнопка "редактировать", "удалить"

Кнопка "редактировать" отправляет пользователя на страницу редактирования агента.
Кнопка "удалить" удаляет агент предварительно запрашивая подтверждение на удаление.

### Создание агента

На форме создания агента можно указать следующие поля:
- имя агента (строка) поле сразу запенено комбинацией из двух случайных английских слов (прилагательное существительное, например: green tower)

Внизу формы доступна кнопка "сохранить" которая переадресует пользователя на страницу редактирования агента.

При создании агента в оркестратор агентов (интерфейс: AgentOrchestratorInterface) отправляется команда о регистрации нового агента (AgentOrchestratorInterface::startAgent). Команда отправялесят в фоновой задаче т.к. процесс может быть длительным. В результатате оркестратор возвращает публичный ключ, который сохраняется в базе и становится доступным для копирования в интерфейсе редактирования агента.

### Редактирование агента

На форме редактирование доступны следующие поля:
- имя агента
- токен (только чтение), рядом с полем доступна кнопка "генерировать", при нажатии в системе создаётся новый JWT который присваивается агенту и отображается в поле
- публичный ключ (только чтение)

Внизу формы доступна кнопка "сохранить" которая переадресует пользователя на страницу со списком агентов.
