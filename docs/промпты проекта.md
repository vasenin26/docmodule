# Промпты проекта

Каждый проект может иметь собственный набор промптов. Редактирование промптов осуществляется через интерфейс расположенный по адресу projects/{projectID}/prompts

В верхней части над формой располагается выпадающий список для выбора типа промпта который нужно отредактировать.

Если промпта выбранного типа нет для проекта, то в форме отображается промпт по умолчанию.

На странице располагается форма редактирования промпта разделённая по вертикали на две панели. В левой части отображается исходный промпт, в правой располагается промпт после обработки шаблонизатором mustache. Обработка шаблонизатором производится с помощью серверной части. Обработки происходит сервисом PromptService реализующим интерфейс PromptProviderInterface . Если метод рендеринга промпта требует параметры то используются поддельные данные.

В нижней части располагается кнопка "сохранить" и "сбросить"

При нажатии кнопки "сбросить" отображается модальное окно с подтверждением действия, при согласии промпт очищается. В форме отображается промпт по умолчанию.

При нажатии кнопки "сохранить" промпт сохраняется для выбранного проекта.
