# Актуализация

Актуализация это процесс приведения состояния страницы документации в соответствие с текущим состоянием присоединённых к странице файлов. Для Актуализации из текущей версии создаётся черновик. Актуализация привязывается к черновику.

## Алгоритм актуализации

При старте актуализации запускается фоновая задача которая производит следующие действия:

* создаётся черновик для страницы
* создаётся запись об актуализации которой прикрепляется черновик 
* запускается чат ЛЛМ с инструкциями по актуализации, в чат передаются следующие сведения:
  * текущий текст страницы
  * список прикреплённых к странице файлов
* новое описание страницы сгенерированное ЛЛМ сохраняется в черновике, ЛЛМ должно стремиться добавить в описание страницы актуальные сведения об алгоритмах применяемых в коде. ЛЛМ обязана сохранить истинность документации. В случае если ЛЛМ обнаруживает расхождение в коде и документации ЛЛМ добавляет в описание страницы сведение об расхождении.  
* чат ЛЛМ прикрепляется к записи актуализации
* черновик отмечается актуализированным
