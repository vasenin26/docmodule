# Проект

Проект является объеденяющей страктурой. Проект пренадлежит менеджеру. Менеджер может создать неограниченное колличество проектов.

## Параметры проекта

Проект имеет следующие свойства:

- id (int) - уникальный идентификатор проекта
- title - название проекта
- owner_id - владелец проекта. 

## Создание проекта

Менеджер может создать проект с помощью формы создания проекта. Проекты созданные менеджером принадлежат этому менеджеру. 

## Список проектов

Список проектов отображает проекты доступные менеджеру. Менеджеру доступны следующие проекты:

- проекты принадлежащие менеджеру

В списке проектов отображаются следующие поля:

- Id проекта
- название проекта

## Параметры проекта

Страница параметров проекта позволяет редактировать свойства проекта. На странице отображаются следующие параметры:

- название проекта
- список репозиториев добавленных проекту

### Репозитории

Менеджер может добавить проекту неограниченный список github репозиториев. При добавлении репозитория менеджер должен указать URL репозитория. Менеджер может удалять репозитории из проекта. Менеджер может добавить как https сыслки так и ssh
