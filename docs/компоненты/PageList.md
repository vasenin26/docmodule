# Компонент PageList

Компонент используется для общего списка страниц.

На данный момент используется чтобы:
- вывести общий список страниц. выводит все страницы
- вывести список страниц на странице проекта. выводит страницы принадлежащие проекту.

## Описание компонента

Компонент представляет собой полнофункциональную таблицу для отображения и управления страницами документации.

### Основные функции:

#### Поиск и фильтрация
- Поле поиска по названию или содержимому страниц
- Кнопки "Найти" и "Очистить" для управления поиском
- Сохранение состояния поиска при навигации

#### Таблица страниц
Отображает следующие колонки:
- **Название** - заголовок страницы с индикаторами:
  - Количество дочерних страниц в скобках
  - Бейдж "Черновик" для страниц с активными черновиками
- **Проект** - название проекта (ссылка) или "Без проекта" (не выводится если проект в параметрах)
- **Создатель** - имя пользователя, создавшего страницу
- **Дата создания** - отформатированная дата в русской локали
- **Дочерние страницы** - список до 3 дочерних страниц с индикацией общего количества
- **Действия** - набор кнопок управления

#### Действия со страницами
- **Просмотр** - переход к просмотру страницы
- **Редактировать/Продолжить** - редактирование (текст кнопки меняется для черновиков)
- **Версии** - просмотр истории версий страницы
- **Удалить** - удаление с подтверждением

#### Дополнительные возможности
- Пагинация для больших списков страниц
- Адаптивный дизайн с горизонтальной прокруткой
- Поддержка как общего списка страниц, так и страниц конкретного проекта
- Кнопка создания новой страницы в заголовке
