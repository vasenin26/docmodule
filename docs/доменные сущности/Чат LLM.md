# Чат LLM

Сущность хранит историю чата в формате JSON и так же размер переписки в токенах модели.  

Нельзя менять историю чата если она была сохранена ранее (поле messages не пустое). В таком случае необходимо создать новую запись. Этим обеспечивается сохранение исторических данных.

Важно! Исторические данные должны быть доступны и неизменяемы. 

Справка: на основе исторических данных рассчитывается расход пользователя.

Важно получать размер переписки в токенах, в случае если сделать это невозможно необходимо сохранить значение "0". Значение по умолчанию null - означает, что размер не рассчитывался.

Сохраняются следующие счётчики токенов:
- токены запроса
- токены ответа
- общее количество потраченных токенов
