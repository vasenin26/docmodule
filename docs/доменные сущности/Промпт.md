Промпт является текстовым шаблоном в формает MD + mustache

Промпт имеет ключ и привязан к проекту. На данный момент имеются следующие виды промптов:

task-manager - промпт для описания роли агента подготавливающего описание задачи
task-descriptoin - промпт для описания интсрукций генерации описания задачи

Список промптов должел быть гелко расширяем.

## Пропмты по умолчанию

Промпты по умолчанию хранятся в файловой системе проекта в папке resource/prompts в формате md.
Имя промпта является его типом (например: task-manager.md)

## Пользовательские промпты

Промпты хранятся в БД в таблице prompts со следующими полями:

- id (int) - идентификатор промпта
- project_id - идентификатор проекта
- type (string) - тип промпта
- content (text) - текст промпта
- created_at
- created_by 

## Порядок предоставвления промпта

Промпты извлекаются сервисом PromptProvider. В первую очередь извлекается промпт проекта, при его отсутвии извлекается промпт по умолчани. После извлечения в промпт проставляются переменные с помощью шаблонизатора mustache.

Не все промпты позволяют вставлять переменные.
