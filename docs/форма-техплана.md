# Форма просмотра задачи

## Описание

Страница просмотра задачи (`/resources/js/pages/tasks/Show.vue`) предназначена для отображения детальной информации о задаче, созданной на основе изменений в документации.

## Структура данных

### Основная структура задачи (TaskData)

Компонент получает объект `task` со следующими полями:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | number | Уникальный идентификатор задачи |
| `content` | string | Автоматически сгенерированное описание задачи в формате Markdown |
| `created_at` | string | Дата и время создания задачи (ISO формат) |
| `updated_at` | string | Дата и время последнего обновления задачи (ISO формат) |
| `page` | PageData | Объект с данными страницы, для которой создана задача |
| `chat_id` | number | Идентификатор связанного чата с LLM |
| `creator` | UserData | Объект с данными пользователя, создавшего задачу |

### Структура данных страницы (PageData)

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | number | Уникальный идентификатор страницы |
| `title` | string | Заголовок страницы |
| `content` | string | Содержимое страницы в формате Markdown |
| `created_at` | string | Дата и время создания страницы (ISO формат) |
| `creator` | UserData | Объект с данными автора страницы |
| `previous_version` | PageVersionData? | Данные предыдущей версии страницы (необязательное поле) |

### Структура данных предыдущей версии (PageVersionData)

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | number | Уникальный идентификатор предыдущей версии |
| `title` | string | Заголовок предыдущей версии |
| `content` | string | Содержимое предыдущей версии в формате Markdown |

### Структура данных пользователя (UserData)

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | number | Уникальный идентификатор пользователя |
| `name` | string | Имя пользователя |
| `email` | string | Email адрес пользователя |

## Отображаемые блоки информации

### 1. Заголовок страницы
- **Заголовок**: "Задача для страницы: {название страницы}"
- **Подзаголовок**: Дата создания и имя создателя задачи
- **Действия**: Кнопка экспорта задачи и ссылка на просмотр страницы, кнопка перезапуска генерации описания.

### 2. Информация о странице
Отображает основные сведения о странице:
- Заголовок страницы
- Автор страницы
- Дата создания страницы
- Предыдущая версия (если существует)

### 3. Описание задачи
- **Содержимое**: Автоматически сгенерированное описание в формате Markdown
- **Обработка**: Рендеринг через компонент `MarkdownRenderer`
- **Пустое состояние**: Сообщение "Описание задачи еще не сгенерировано". Если описание не сформировано, система атоматически делает запрос к серверу, чтобы проверить текущее состояние генерации описания. Как только описаное сформировано, оно сразу отображается в интерфейсе.

### 4. Сравнение версий (отображается только при наличии предыдущей версии)

#### Изменения заголовка
- **Условие отображения**: Если заголовок текущей версии отличается от предыдущей
- **Визуализация**: 
  - Красный блок с предыдущим заголовком (метка "Было:")
  - Зеленый блок с текущим заголовком (метка "Стало:")

#### Изменения содержимого
- **Условие отображения**: Если содержимое текущей версии отличается от предыдущей
- **Визуализация**:
  - с блоке отображается diff версий, в качества референса отображения испльзуется формат выводы данных команды git diff
- **Ограничения**: Максимальная высота блоков 40 (10rem) с вертикальной прокруткой

### 5. Метаинформация
Дополнительные технические данные:
- ID задачи
- ID страницы
- Создатель задачи
- Дата создания задачи

## Используемые компоненты

- `AppLayout` - основной макет приложения
- `Heading` - компонент заголовка
- `MarkdownRenderer` - рендеринг Markdown контента
- `TaskExportButton` - кнопка экспорта задачи
- `Button`, `Card`, `Label` - UI компоненты из библиотеки

## Функциональность

### Форматирование даты
Функция `formatDate` преобразует ISO дату в локализованный формат:
- Язык: русский (ru-RU)
- Формат: "день месяц год, час:минута"
- Пример: "15 января 2024, 14:30"

### Навигация
- Ссылка "К странице" ведет на страницу просмотра документации (`pages.show`)
- Кнопка экспорта для выгрузки данных задачи
- Кнопка перезапуска генерации описания доступна только если в настоящий момент не происходит генерация. При нажатии на кнопку генерация описания запускается заново.

## Условная логика отображения

1. **Описание задачи**: Отображается только если поле `content` не пустое
2. **Блок сравнения версий**: Отображается только при наличии `previous_version`
3. **Изменения заголовка**: Показываются только при различии заголовков
4. **Изменения содержимого**: Показываются только при различии содержимого
5. **Предыдущая версия в информации о странице**: Отображается только при наличии `previous_version`

## Стилизация

- Использует Tailwind CSS классы
- Цветовая схема различий: красный для удаленного, зеленый для добавленного
- Адаптивная сетка (responsive grid) для отображения на разных устройствах

## Чат с LLM
