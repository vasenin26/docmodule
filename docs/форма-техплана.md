# Форма просмотра техплана

## Описание

Страница просмотра техплана (`/resources/js/pages/techplane/Show.vue`) предназначена для отображения детальной информации о техплане, созданной на основе связанной задачи.

## Структура данных

Техплан содержит следующие поля.

| Поле         | Тип | Описание                                                             |
|--------------|-----|----------------------------------------------------------------------|
| `id`         | number | Уникальный идентификатор техплана                                    |
| `content`    | string | Автоматически сгенерированное содержимое техплана в формате Markdown |
| `created_at` | string | Дата и время создания задачи (ISO формат)                            |
| `updated_at` | string | Дата и время последнего обновления задачи (ISO формат)               |
| `page`       | PageData | Объект с данными страницы, для которой создана задача                |
| `chat_id`    | number | Идентификатор связанного чата с LLM                                  |
| `taks_id`    | number | Идентификатор связанной техпланом задачи                             |
| `creator`    | UserData | Объект с данными пользователя, создавшего задачу                     |
