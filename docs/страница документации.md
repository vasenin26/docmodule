# Страница документации

"Страница документации" (далее "страница") является основной сущностью в системе управления документацией.
Страница имеет следующие свойства

* id (int) - уникальный идентификатор страницы, генерируется автоматически
* title (varchar) - текстовое название страницы
* content (text) - текстовое содержимое страницы, может быть тесктом большого объёма в формате Markdown
* created_by - ID полователя создавшего страницу
* created_at - дата создания страницы
* base_id (int|null) - ID первой версии страницы в цепочке обновлений. Для первой версии страницы поле равно собственному ID, для последующих версий указывает на первую версию
* previous_version_id (int|null) - ID предыдущей версии страницы в цепочке обновлений. Для первой версии страницы поле пустое
* parent_id - родительская страница в древовидной иерархии
* current - флаг указывающий эта версия является текущей и отображается в админке. У каждой страницы может быть только одна текущая версия

Страницы могут иметь дочерние страницы.

Каждая страница может иметь цепочку версий, где каждая версия связана с предыдущей через поле previous_version_id. Первая версия страницы имеет пустое поле previous_version_id, а поле base_id указывает на саму себя. Последующие версии имеют base_id равный ID первой версии и previous_version_id равный ID предыдущей версии.

При редактировании страницы, новая версия создаётся как новая запись в базе с указанием в поле base_id идентификатора первой версии и в поле previous_version_id идентификатора предыдущей версии. Эта версия считается черновиком, до тех пор пока не будет утверждена. 
Пользователь может редактировать черновик много раз.
Это позволяет построить полную цепочку обновлений от первой до последней версии.
Если при начале редактирование у этой страницы уже есть черновик, то система предлагает продолжить редактирование последнего черновика созданного из текущей версии. Таким образом, если пользователь утверждает новую версию, все черновики созданные от другой версии больше не доступны для редактирования и для редактирования пользователю нужно начать новое редактирование последней утверждённой версии страницы.
Пользователь может утвердить черновик и тогда эта версия страницы становится текущей. 

## Описание задачи

Если отображаемой версии страницы есть прикреплённое описание задачи, то в интерфейсе отображения страницы документации отображаются общие сведения о задачи с кнопкой позволяющая перейти на страницу задачи.

## Дополнительные действия

* На форме редактирования черновика есть флажок "создать задачу"
* Если на форме редактирования черновика страницы отмечен флажок "создать задачу", то при утверждении задачи сразу создаётся новая задача и пользователь после сохранения формы переадресуется на страницу новой задачи.
