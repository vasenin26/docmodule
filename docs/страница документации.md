# Страница документации

"Страница документации" (далее "страница") является основной сущностью в системе управления документацией.
Страница имеет следующие свойства

* id (int) - уникальный идентификатор страницы, генерируется автоматически
* parent_id - родительская страница в древовидной иерархии
* version_id - ID текущей версии
* created_by - ID пользователя создавшего страницу
* created_at - дата создания страницы
* deleted_by - ID пользователя удалившего страницу
* deleted_at - дата удаления страницы

## Контент

Содержимое страницы является версионируемым и хранится в отдельной таблице (PageVersions) со следующими полями:

* id - ID версии
* page_id (int) - ID страницы
* title (varchar) - текстовое название страницы
* content (text) - текстовое содержимое страницы, может быть тесктом большого объёма в формате Markdown
* previous_version_id (int|null) - ID предыдущей версии страницы в цепочке обновлений. Для первой версии страницы поле пустое
* files - массив ссылок на файлы в репозитории

## Общее положение

Страницы могут иметь дочерние страницы. Отображаются только текущие версии дочерних страниц.

Каждая страница может иметь цепочку версий, где каждая версия связана с предыдущей через поле previous_version_id. Первая версия страницы имеет пустое поле previous_version_id.

При редактировании страницы, новая версия создаётся как новая запись в базе с указанием в поле page_id идентификатора страницы и в поле previous_version_id идентификатора предыдущей версии. Эта версия считается черновиком, до тех пор пока не будет утверждена. 
Пользователь может редактировать черновик много раз.
Это позволяет построить полную цепочку обновлений от первой до последней версии.
Если при начале редактирование у этой страницы уже есть черновик, то система предлагает продолжить редактирование последнего черновика созданного из текущей версии.
Пользователь может утвердить черновик и тогда эта версия страницы становится текущей. 

## Описание задачи

Если отображаемой версии страницы есть прикреплённое описание задачи, то в интерфейсе отображения страницы документации отображаются общие сведения о задачи с кнопкой позволяющая перейти на страницу задачи.

## Дополнительные действия

* На форме редактирования черновика есть флажок "создать задачу"
* Если на форме редактирования черновика страницы отмечен флажок "создать задачу", то при утверждении задачи сразу создаётся новая задача и пользователь после сохранения формы переадресуется на страницу новой задачи.   
* На форме редактирования доступна возможность редактировать список файлов прикреплённых к странице. Список реализован как отдельный компонент
* В верхнем меню доступна кнопка "актуализировать" которая запускает процесс актуализации для страницы.
