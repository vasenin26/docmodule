Состема создаёт задачи в таск-трекере при создании новой страницы или новой версии существующей страницы документации.

В момент создания новой версии, система создаёт задачу (job) для вычисления разинцы между старой и новой версиями страницы документации, затем на основе полученных данных в системе создаётся задача (job) на генерацию описания новой задачи.
После гереции описания задачи создаётся задача (job) для создания новой задачи в таск трекере.


## Генератор описания

На текущем этапе в качестве генератора описания выступает простой сервис-заглушка который проксирует дальше переданные в него сведения. Проще говоря - генерация не проводится.

## Создание новой задачи в трекере

На даном этапе для создания задачи в трекере используется FakeIntegration
