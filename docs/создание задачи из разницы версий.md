При отверждении черновика страницы в интерфейсе страницы появляется кнопка "создать задачу". При нажатии на кнопку в системе создаётся новая задача.

Для описания в базе создаётся запись в таблице VersionDiffTask, при создании записи генерируется новый ID. Запись имеет следующие поля:

id (int) - идентификатор задачи
page_id - идентификатор версии страницы для которой создаётся задача. Задача формируется на основе контента этой версии и предыдущей версии страницы. 
project_id - проект к которому привязана задача
content - описание задачи.
created_by - идентификатор пользователя создавший задачу

В момент утверждения версии, система создаёт задачу (job) для вычисления разницы между старой и новой версиями страницы документации, затем на основе полученных данных в системе создаётся задача (job) на генерацию описания новой задачи.

## Вычисление разницы

Разница между старой и новой версией документации вычисляется построчно, в итоговый результат попадаются как новые так и старые версии строк, но не попадают строки в которых небыло изменений.

```Пример
+ Эта строка была добавлена
- Эта строка была удалена
```

В качестве референса вывода разницы используется вывод команды git diff
