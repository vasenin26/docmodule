# Система интеграции с таск-трекером

Система позволяет взаимодействовать с внешнийми таск-трекерами. Взаимодействие заключается в следующих действиях:

* создание новой задачи в трекере, при создании передаётся название задачи и описание

Система имеет расширяему архитектуру и позволяет свободно добавлять интеграцию с новыми трекерами задачь путём реализации интерфейса обисывающего основные функции.
