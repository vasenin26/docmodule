# Система интеграции с таск-трекером

Система позволяет взаимодействовать с внешнийми таск-трекерами. Взаимодействие заключается в следующих действиях:

* создание новой задачи в трекере, при создании передаётся название задачи и описание

Система имеет расширяему архитектуру и позволяет свободно добавлять интеграцию с новыми трекерами задачь путём реализации интерфейса обисывающего основные функции.

На текущем этапе реализации добавить следующую интеграцию:

* FakeIntergation - это интеграция не связывается со сторонными сервисами, а просто выводи данные в консоль. Используется в целях отладки.

Пользовательский интерфейс для взаимодействия с системой не трубуется. На данном этапе система только обеспечивает возможность интегарции, но не используется в проекте. 

Для управления интеграциями так трекером используется раздел настроек "Менеджер задач"
