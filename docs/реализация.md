# Реализация

Реализация является структурой хранящей информацию о выполнении агентом техплана.
При создании реализации создаётся чат и задача для агента. Чат привязывается к реализации.

После обработки задачи агентом, в реализацию записывается описание внесённых изменений и статус реализации.

Хранимые значения:

- id
- content
- techplane_id
- chat_id

Реализацию и связанный чат можно просмотреть на отдельной странице.
