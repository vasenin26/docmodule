# Основные положения

Всё взаимодействие с системой документации внутри проекта должно происходить с помощью сервиса DocumentationControl, таким образом данный сервис аккмулирует бизнес правила по которым формируются текущие версии страниц, а так же черновики. В частности сервис позволяется:

- получить текущую версию страницы
- получить список текущих версий страниц с помощью фильтра PageFilter

Сервис является частью системы, по этому доменные сущности системы являются элементами сервиса.
Сервис предоставляет агрегат CurrentPage в который содержаться все сведения о текущей версии страницы.
