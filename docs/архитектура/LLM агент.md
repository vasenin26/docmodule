LLM Агент (далее "агент") имеет доступ к следующей информации:

- страницы документации в рамках проекта для которого происходит генерация
- гит-хаб репозитории прикреплённые к проекту

# Интерфейс LLMGenerator

Агенты должны реализовывать интерфейс LLMGenerator. Внедрение агентов реализуется через фабрику агентов реализующую интерфейс AgentFactory, которая предоставляет агентам функции в качестве зависимостей - это обеспечивается согласованность функций доступных пользователю запускающего агента.
