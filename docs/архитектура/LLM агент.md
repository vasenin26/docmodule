LLM Агент (далее "агент") имеет доступ к следующей информации:

- страницы документации в рамках проекта для которого происходит генерация
- гит-хаб репозитории прикреплённые к проекту

Агент является внешней системой, которая общается с сервисом через АПИ.

## Сервис управления задачами агента

Сервис реализует AgentTaskManagerInterface

Чтобы создать новую задачу, необходимо предоставить сервису:

- handler реализующий интерфейс AgentResultHandlerInterface
- проект к которому привязана задача
- ID чата с сообщениями

Будет создана новая задача в которой сохранены переданные сведения.

## Задачи агента

Задачи хранятся в таблице AgentTask со следующими полями

- *id*
- *type* - тип задачи, может быть text || code
- *handler (string)* - обработчик результата задачи
- *handler_options (json)* - дополнительные параметры обработчика
- *project_id* - проект к которому привязана задача
- *created_by* - пользователь создавший задачу
- *chat_id* - чат привязанный к задаче
- *status* - статус задачи

## Обработка задачи внешним агентом

Запущенный агент обращается к системе по адресу: 

POST: /api/agent/task 

Ресурс возвращает задачу со статусом wait к которой у Агента есть доступ.

С этого момента задача считается закреплённой за агентом, переходит в статус processing 
В процессе работы агент обновляет состояние задачи передавая информацию по адресу:

PUT: /api/agent/task/{id}

{
type: string
chat: LLMMessageDTO[] - список сообщений в чате
stats: LLMResultDTO - количество потраченных токенов
result: string|null - результат подготовленный LLM
}

При получении сообщения сервис обновляет запись чата, 
сохраняя список сообщений и суммирует израсходованные токены со значениями ранее сохранёнными для чата. 

Как только агент передаёт результат, задача считается выполненной - статус success
Результат передаётся обработчику результата.
