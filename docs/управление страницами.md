# Система управления страницами

Система состоит из следующих компонентов^
* список страниц
* форма редактирования страницы

## Список страниц

Список страниц - страница приложения на которой отображаются все текущие версии страниц. Список отображается в виде таблицы.

В верхней части списка страниц располагается панель с действиями для управления страниц. Доступные действия:

* созда страницу - открывает форму редактирование страницы новой страницы.

## Форма редактирования страниц.

Форма редактирования применяется для редактирования страниц документации.
Форма редактирования позволяет редактировать следующие поля:

* title - заголовок страницы, редактирование с помощью тестового поля ввода
* content - контент редактируется с помощью textarea
