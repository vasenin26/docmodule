# Список задач

При выборе проекта в боком меню доступен список задач.
Список выводится в виде таблицы со следующими колонками:
 
- ID
- Дата создания
- Статус 
- Действия - (открыть, удалить)

Над таблицей доступен блок с действиями:

- "создать" - создаёт новую задачу в рамках проекта и открывает форму редактирования
