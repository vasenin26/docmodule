# Форма редактирования задачи

Форма содержит редактируемое поле с описанием задачи.
Так же на форма дополнительно отображается блок с разницей на основе которой была сформирована задача.

## Привязанные страницы

В правой части экрана расположен список привязанных к задаче страниц. 
Список можно редактировать удаляя страницы.
Внизу списка располагается кнопка "привязать страницу", при нажатии на которую открывается модальное окно со списком страниц и формой поиска.
Страницы ищутся по совпадению заголовка или частичному совпадению содержимого текущей версии страницы. Поиск происходит только текущих версий страниц.

## Доступные действия
Внизу формы доступна кнопка "сохранить", при сохранении пользователь возвращается на форму просмотра задачи.

При сохранении задачи, техплан прикреплённый к задаче очищается.
