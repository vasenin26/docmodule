# Перечисление доменных сущностей проекта

* *Пользователь* - авторизованный пользователь системы
* *Менеджер* - пользователь системы
* *Проект* - совокупность параметров и страниц документации. Проект принадлежит менеджеру.
* *Документация* - совокупность текущих версий всех страниц. Документация является абсолютной истиной, если код противоречит документации, то код должен быть приведён в состояние соответсвующее документации.
* *Страница* - страница документации.
* *Версия страницы* - каждая страница документации может иметь несколько версий, но только одна версия может являться текущей. Текущая версия документации является истинной.
* *Задача* - текстовое описание описывающее изменения необходимые для приведения приложения к текущему состоянию документации. Задача является текстом от менеджера к разработчику.
* *Техплан* - текстовое описание описывающие изменения необходимые для реализации требований описанных в задаче. Техплан это документ для младшего разработчика, может содержать технические детали, а так же точные примеры реализации. Задача может иметь только один технический план.
* *Репозиторий* - удалённое хранилище кода с поддержкой системы контроля версий git.
* *Чат LLM* - лог сообщений с LLM, хранится в виде JSON структуры. 
* *Промпт* - текстовый шаблон предоставляемый LLM в качестве инструкции
