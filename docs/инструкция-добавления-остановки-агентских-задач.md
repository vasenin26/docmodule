# Инструкция: Добавление поддержки остановки агентских задач

## Описание

Данная инструкция описывает необходимые шаги для добавления функционала остановки агентских задач в чатах различных сущностей (задачи, техпланы, реализации).

## Требуемые элементы

### 1. Backend изменения

#### 1.1. Маршруты (routes/web.php)

Добавить PUT маршруты для остановки генерации:

```php
// Для техпланов
Route::put('techplanes/{techplane}/stop-generating', [TechplaneController::class, 'stopGenerating'])
    ->name('techplanes.stop-generating');

// Для реализаций  
Route::put('implementations/{implementation}/stop-generating', [ImplementationController::class, 'stopGenerating'])
    ->name('implementations.stop-generating');
```

#### 1.2. Контроллеры

Добавить метод `stopGenerating()` в соответствующие контроллеры:

**TechplaneController.php:**
```php
use App\Models\AgentTask;

/**
 * Остановить генерацию агентских задач для техплана
 */
public function stopGenerating(Techplane $techplane, AgentTaskManagerInterface $agentTaskManager): JsonResponse
{
    $agentTasks = AgentTask::where([
        'chat_id' => $techplane->chat_id,
        'status' => AgentTask::STATUS_PROCESSING
    ])->get();

    $stoppedTasks = [];

    foreach ($agentTasks as $agentTask) {
        $agentTaskManager->stopTask($agentTask->id);
        $stoppedTasks[] = $agentTask->id;
    }

    return response()->json([
        'techplane_id' => $techplane->id,
        'agent_task_id' => $stoppedTasks,
        'chat_id' => $techplane->chat_id,
        'message' => 'Генерация техплана успешно остановлена',
        'success' => true
    ]);
}
```

**ImplementationController.php:**

### 2. Frontend изменения

#### 2.1. API Request классы

Создать TypeScript классы для API запросов:

**TechplaneStopGeneratingRequest.ts:**
```typescript
import { Method, type ApiInterface, type Request } from '@/service/api/Api';

export interface TechplaneStopGeneratingResponse {
    success: boolean;
    message: string;
    techplane_id: number;
    agent_task_id: number[];
    chat_id: number;
}

export class TechplaneStopGeneratingRequest implements Request<TechplaneStopGeneratingResponse> {
    public readonly method: Method;
    public readonly url: string;
    public readonly body: any;

    constructor(techplaneId: number) {
        this.method = Method.UPDATE;
        this.url = route('techplanes.stop-generating', techplaneId);
        this.body = null;
    }

    public async call(api: ApiInterface): Promise<TechplaneStopGeneratingResponse> {
        return api.execute<TechplaneStopGeneratingResponse>(this);
    }
}
```

## Порядок реализации

1. **Backend изменения:**
   - Добавить маршруты в `app/routes/web.php`
   - Добавить методы `stopGenerating()` в соответствующие контроллеры

2. **Frontend API requests:**
   - Создать TypeScript классы для API запросов

3. **Frontend composables:**
   - Обновить composable функции с функцией `stopGenerating()`

4. **Frontend страницы:**
   - Обновить Vue страницы с обработчиком `@stop="sendStopGenerating"`

## Принципы работы

- **Безопасность:** Останавливаются только активные задачи агента (`STATUS_PROCESSING`) для конкретного чата
- **Единообразие:** Все чаты имеют одинаковый функционал остановки
- **UX:** Пользователь может прервать долгую генерацию в любой момент
- **Архитектура:** Используется существующий паттерн из задач, минимизируя изменения
