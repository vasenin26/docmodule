# Форма редактирования задачи

Форма содержит редактируемое поле с описанием задачи.
Так же на форма дополнительно отображается блок с разницей на основе которой была сформирована задача.

Внизу формы доступна кнопка "сохранить", при сохранении пользователь возвращается на форму просмотра задачи.

При сохранении задачи, техплан прикреплённый к задаче очищается.
