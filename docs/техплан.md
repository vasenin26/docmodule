# Форма просмотра техплана

## Описание

Страница просмотра техплана (`/resources/js/pages/techplane/Show.vue`) предназначена для отображения детальной информации о техплане, созданной на основе связанной задачи.

## Структура данных

Техплан содержит следующие поля.

* id (int) - уникальный идентификатор
* task_id - идентификатор задачи на основе которого был сгенерировать техплан
* content - текст техплана в формате md
* created_by - идентификатор создателя техплана
* chat_id - связанный чат LLM использованный для генерации техплана

## Форма техплана

На форме техплана располагаются следующие блоки:

- метаинформацию техплана
- описание техплана

## Доступные действия

- экспортировать - в текущей реализации кнопка не активна (заглушка)
- чат - по нажатию открывает модальное окно с чатом LLM с помощью которого сгенерирован техплан. если чат не прикреплён к техплану, то кнопка не отображается.
