# Форма просмотра техплана

## Описание

Страница просмотра техплана (`/resources/js/pages/techplane/Show.vue`) предназначена для отображения детальной информации о техплане, созданной на основе связанной задачи и файлов прикреплённых к странице документации на основе которых была создана задача.

## Структура данных

Техплан содержит следующие поля.

* id (int) - уникальный идентификатор
* task_id - идентификатор задачи на основе которого был сгенерировать техплан
* content - текст техплана в формате md
* created_by - идентификатор создателя техплана
* chat_id - связанный чат LLM использованный для генерации техплана

## Форма техплана

На форме техплана располагаются следующие блоки:

- метаинформацию техплана
- описание техплана

В верхней панели техплана располагаются кнопки:

* "к задаче" - возвращают пользователя на форму задачи к которой прикреплён техплан  

## Доступные действия

- экспортировать - в текущей реализации кнопка не активна (заглушка)
- выполнить - кнопка доступна если техплан сгенерировать, при нажатии на кнопку создаётся новое "исполнение". пользователь переадресуется на страницу исполнения.
- чат - по нажатию открывает модальное окно с чатом LLM с помощью которого сгенерирован техплан. если чат не прикреплён к техплану, то кнопка не отображается.
