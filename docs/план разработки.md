# План разработки функционала управления страницами документации

## Обзор проекта

Проект построен на Laravel 12 с использованием:
- **Backend**: Laravel + Inertia.js
- **Frontend**: Vue 3 + TypeScript + Tailwind CSS
- **UI Framework**: Reka UI (компоненты)
- **База данных**: SQLite (по умолчанию)

## Анализ требований

### Модель данных "Страница документации"

Страница имеет следующие поля:
- `id` (int) - уникальный идентификатор
- `title` (varchar) - название страницы
- `content` (text) - содержимое в формате Markdown
- `created_by` (int) - ID пользователя-создателя
- `created_at` (timestamp) - дата создания
- `base_id` (int|null) - ID базовой страницы для версионирования
- `parent_id` (int|null) - ID родительской страницы
- `current` (boolean) - флаг текущей версии

### Функциональные требования

1. **Список страниц** - таблица с текущими версиями
2. **Форма редактирования** - создание/редактирование страниц
3. **Версионирование** - создание новых версий при редактировании
4. **Иерархия** - поддержка дочерних страниц

## Технические детали

### База данных

```sql
CREATE TABLE pages (
    id BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255) NOT NULL,
    content TEXT,
    created_by BIGINT UNSIGNED NOT NULL,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    base_id BIGINT UNSIGNED NULL,
    parent_id BIGINT UNSIGNED NULL,
    current BOOLEAN DEFAULT FALSE,
    
    FOREIGN KEY (created_by) REFERENCES users(id),
    FOREIGN KEY (base_id) REFERENCES pages(id),
    FOREIGN KEY (parent_id) REFERENCES pages(id),
    
    INDEX idx_current (current),
    INDEX idx_parent_id (parent_id),
    INDEX idx_created_by (created_by)
);
```

### API Endpoints

```php
// Список страниц
GET /api/pages
GET /api/pages?parent_id=1
GET /api/pages?search=query

// Создание страницы
POST /api/pages

// Обновление страницы
PUT /api/pages/{id}

// Удаление страницы
DELETE /api/pages/{id}

// Версии страницы
GET /api/pages/{id}/versions
POST /api/pages/{id}/restore/{version_id}
```
