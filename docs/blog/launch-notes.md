# Запуск публичного блога

Мы добавили в сервис отдельный публичный раздел блога.

## Что уже работает

- Список постов доступен по адресу `/blog`.
- Детальная страница поста доступна по адресу `/blog/{slug}`.
- Контент читается из Markdown-файлов в каталоге `docs/blog`.

## Зачем это нужно

Этот раздел фиксирует историю развития продукта и делает изменения прозрачными для пользователей.

## Как публиковать

1. Создайте `.md` файл в `docs/blog`.
2. Используйте `kebab-case` в имени файла, например `my-first-post.md`.
3. Добавьте заголовок первого уровня (`#`) в начале файла.
