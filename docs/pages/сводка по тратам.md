# Сводка расходов

В проекте доступна сводка по расходам. Расходы формируются из cost AgentTask

Сводка выглядит как горизонтальный график с барами. 
Каждый это временной период.

Можно выбрать временные периоды:
- день
- неделя
- месяц

Можно выбрать временной промежуток отображения, выполнен в виде двух полей с выбором дат.

Доступен фильтр со списоком AgenTaskType
