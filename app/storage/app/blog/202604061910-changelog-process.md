# Как мы ведем changelog

В проекте теперь есть регулярный ритуал обновления истории изменений.

## Правила

- Каждая рабочая сессия заканчивается короткой заметкой в блоге.
- В changelog добавляются только заметные изменения для пользователей.
- История хранится в репозитории и проходит code review вместе с кодом.

## Плюсы подхода

- Быстро восстановить контекст после паузы.
- Понятно, почему были приняты конкретные решения.
- Легко показывать прогресс по проекту публично.
